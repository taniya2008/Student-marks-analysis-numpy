# Contributing to Student Marks Analysis

First off, thanks for considering contributing to this project! 🎉

## Code of Conduct

Be respectful and inclusive. Treat everyone with kindness.

## How Can I Contribute?

### Reporting Bugs 🐛

- Check if the bug has already been reported
- When reporting, include:
  - Python version
  - NumPy version
  - Steps to reproduce
  - Expected vs actual behavior
  - Screenshots if applicable

### Suggesting Enhancements 💡

- Use the Issues tab with clear description
- Explain the use case
- List some alternatives you've considered

### Pull Requests

1. Fork the repository
2. Create a new branch: `git checkout -b feature/AmazingFeature`
3. Make your changes
4. Commit with clear messages: `git commit -m 'Add AmazingFeature'`
5. Push to the branch: `git push origin feature/AmazingFeature`
6. Open a Pull Request

## Style Guide

- Use PEP 8 for Python code
- Add docstrings to functions
- Write clear comments for complex logic
- Keep lines under 100 characters

## Development Setup

```bash
git clone https://github.com/yourusername/student-marks-analysis.git
cd student-marks-analysis
pip install -r requirements.txt
python project.py
```

## Questions?

Feel free to open an issue with the label `question`. We're here to help! 😊

Happy coding! 🚀
