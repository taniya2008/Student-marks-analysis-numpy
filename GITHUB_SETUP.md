# 🚀 Quick GitHub Setup Guide for Taniya

## Step 1: Create a GitHub Repository

1. Go to [github.com/new](https://github.com/new)
2. Fill in the details:
   - **Repository name**: `student-marks-analysis`
   - **Description**: `A beginner-friendly NumPy project for analyzing student exam marks with statistical insights.`
   - **Public** (so people can see your work!)
   - ⚠️ **DO NOT** initialize with README, .gitignore, or license (we already have them!)

3. Click **Create repository**

## Step 2: Push Your Code to GitHub

Copy and paste these commands in your terminal (one by one):

```bash
# Navigate to your project folder
cd path/to/student-marks-analysis

# Initialize git
git init

# Add all files
git add .

# Create first commit
git commit -m "Initial commit: Student marks analysis using NumPy"

# Rename branch to main
git branch -M main

# Add remote origin (replace with your setup)
git remote add origin https://github.com/taniya2008/student-marks-analysis.git

# Push to GitHub
git push -u origin main
```

## Step 3: ✨ Done!

Your repo is now live at: **https://github.com/taniya2008/student-marks-analysis**
